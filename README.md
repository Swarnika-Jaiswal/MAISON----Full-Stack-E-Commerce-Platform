## 🛍️ About MAISON

MAISON is a full-stack e-commerce and order management platform designed to provide a seamless shopping experience alongside powerful administrative capabilities.

It covers the complete commerce lifecycle:

**Product Discovery → Shopping Cart → Checkout → Payment → Order Processing → Delivery → Returns**

The platform combines a React-based frontend with a Node.js and Express backend, MongoDB persistence, real-time communication, caching, payment integration, and AI-powered review summaries.

## ⭐ Key Features

| Customer Experience | Admin Workspace |
|:---|:---|
| 🔐 Secure authentication | 📊 Analytics dashboard |
| 🛒 Shopping cart & wishlist | 📦 Product management |
| 🔎 Product search & filtering | 🚚 Order management |
| 💳 Payment integration | 👥 User management |
| ⭐ Reviews & AI summaries | 🎟️ Coupon management |
| 📍 Order tracking | 💰 Returns & refunds |

**Additional capabilities:** Google OAuth, two-factor authentication, email notifications, background jobs, and real-time order updates.

## 🚀 Getting Started

**Prerequisites:** Node.js, npm, MongoDB, and the required service credentials.

```bash
# Clone this repository
git clone https://github.com/Swarnika-Jaiswal/MAISON----Full-Stack-E-Commerce-Platform.git

# Navigate to the project
cd MAISON----Full-Stack-E-Commerce-Platform

# Install backend dependencies
npm install

# Install frontend dependencies
cd frontend
npm install
```

Configure the backend environment variables using the existing environment configuration example, then start the backend and frontend using the scripts defined in their respective `package.json` files.

> Note: Redis, Elasticsearch, Cashfree, AWS S3, Google OAuth, SMTP, and Gemini features require their corresponding service configurations.
